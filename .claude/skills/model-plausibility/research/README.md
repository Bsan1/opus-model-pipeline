# Research per kind of object

One file per kind of object (`tire-swing.md`, `push-mower.md`, ...), written before its first model (SKILL.md, step 2b) and read instead of searching again for the next one of its kind. Keep each file short.

```markdown
# <kind>
Researched: <date>, for <model>
## Sources
- <title> (<link>): <what was taken from it>
## Adopted
- <trick or fact> -> <where it is used: generator, part, plan component>
## Rejected
- <trick> - <why: our stylised look, our pipeline, contradicts the source frames>
```
